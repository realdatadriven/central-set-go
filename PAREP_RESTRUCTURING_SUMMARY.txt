WHAT WAS CHANGED
================

1. NEW TABLE: AMBITOS
   - Purpose: Classify objectives by scope
   - Values: 1=Pré-escolar, 2=1º Ciclo
   - Enables filtering and organization

2. RENAMED TABLES
   - resultados → OBJETIVOS (now 7 instead of 2)
   - atividades → RESULTADO_ESPERADOS

3. UPDATED FOREIGN KEYS
   - INDICADORES: resultado_id → objetivo_id
   - ATIVIDADE_ANOS: atividade_id → resultado_esperado_id
   - ACOES, CONTRATOS, LOGISTICA, BENEFICIARIOS: Updated accordingly

4. NEW DATA STRUCTURE
   - 7 Strategic Objectives (4 Pré-Escolar, 3 1º Ciclo)
   - 28 Expected Results (bullets per objective)
   - 40 Indicators (with 2021 baseline and 2026 targets)
   - All organized in parep_data_objetivos.sql

KEY DIFFERENCES: Old vs New
===========================

OLD STRUCTURE:
  Resultados (2) → Atividades → Atividade_Anos → Ações
  
  - Only 2 top-level results (Pré-Escolar, 1º Ciclo)
  - Activities were the main organizational unit
  - Indicators tied directly to results

NEW STRUCTURE:
  Ambitos → Objetivos (7) → Resultado_Esperados → Atividade_Anos → Ações
  
  - 2 scopes (Pré-Escolar, 1º Ciclo)
  - 7 strategic objectives
  - Expected results as explicit outputs
  - Indicators tied to objectives
  - Clearer hierarchy and semantics
