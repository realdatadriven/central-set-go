# GOOGLE DRIVE STORAGE
# ============================================================
#
# Setup:
#
# 1. Open Google Cloud Console:
#    https://console.cloud.google.com/
#
# 2. Create or select a Google Cloud project.
#
# 3. Enable the Google Drive API:
#    APIs & Services -> Library -> Google Drive API -> Enable
#
# 4. Create a Service Account:
#    IAM & Admin -> Service Accounts -> Create Service Account
#
#    Example:
#      Name: c7-storage
#      ID:   c7-storage
#
# 5. Create a JSON key for the service account:
#    Service Account -> Keys -> Add Key -> Create new key -> JSON
#
#    Store the downloaded JSON securely.
#    DO NOT commit this file to Git.
#
# 6. IMPORTANT: Share the Google Drive folder with the service account.
#
#    a) Open the downloaded service-account JSON file.
#
#    b) Find the "client_email" field:
#
#       "client_email": "c7-storage@my-project-123.iam.gserviceaccount.com"
#
#    c) Copy that email address EXACTLY.
#
#    d) In Google Drive, right-click the folder where files should be
#       stored -> Share.
#
#    e) Add the service account email:
#
#       c7-storage@my-project-123.iam.gserviceaccount.com
#
#       The email normally has this format:
#
#       <service-account-name>@<project-id>.iam.gserviceaccount.com
#
#    f) Give the service account "Editor" permission.
#
#    The service account does NOT have to be the owner of the folder.
#    It only needs access to the folder.
#
# 7. Get the Google Drive folder ID.
#
#    Open the folder in Google Drive. The URL will look like:
#
#      https://drive.google.com/drive/u/0/folders/1ABCxyz123...
#
#    The value after "/folders/" is the folder ID.
#
#    Example:
#
#      URL:
#      https://drive.google.com/drive/u/0/folders/1HDkacugl3cNbtWPeRqZZM42W-M6JZwWs
#
#      Folder ID:
#      1HDkacugl3cNbtWPeRqZZM42W-M6JZwWs
#
# 8. Configure the variables below.
#
#    GOOGLE_DRIVE_CREDENTIALS_FILE must point to the service-account
#    JSON file created in step 5.
#
#    GOOGLE_DRIVE_FOLDER_ID must contain the ID from step 7.
#
#    The folder from step 7 must have been shared with the
#    service-account email from step 6.
#
# ============================================================
